Date: 14 October 2026. Scope: local container packaging and keyless acceptance. [Machine-readable results](m17-docker.json) preserve the checks.

## Delivered

- Multi-stage `Dockerfile` with Node 24.15.0, pnpm 12.11.2, native dependencies, FFmpeg/FFprobe and Noto fonts.
- Built web image with NGINX SPA fallback, same-origin API proxying, SSE buffering disabled and WebSocket upgrade headers.

- Non-root API/migration user, loopback-only published web port and private runtime `.env.docker` configuration.
- [Docker guide](../docker.md), README quickstart and source-package inclusion.
