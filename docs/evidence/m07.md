## Issues discovered and corrected

Flash Lite repeatedly rejected valid paraphrases in evidence review and sometimes failed the structured grading output. Failed jobs preserved learner input and did not award progress. Luna completed the same workflow; evaluation now has a separate explicit model setting with no automatic fallback.

An early uncertainty application was marked incorrect because reasoning was absent. Application review now independently classifies correct reasoning, explicit contradiction, and insufficient evidence. The server downgrades disagreement or insufficient evidence to null/limited, with calibrated feedback. A repeated "I don't know" case remained unknown. The original development attempt remains in history; historical outputs were not silently rewritten.

These observations establish implemented behavior for the sample cases. They are automated educational judgments, not native-language review, expert validation, or measured learning outcomes. M08 and M12 retain those review records and broader checks.
