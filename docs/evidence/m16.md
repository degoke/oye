## Limits of these checks

The ignored local `.env` remains explicitly configured for OpenRouter to preserve the existing demo. There is no direct OpenAI key in this workspace, so live OpenAI generation, search and speech quality are unverified. No full test suite, new paid generation, hosted deployment or physical-device review was performed for this milestone. Prior language/device acceptance decisions and failed media reviews remain intact.

The screenshot tour is readable without a runtime. Its main learning sequence is photosynthesis; the video/offline screens show a separate compound-interest feature example. [Capture metadata](../assets/walkthrough/captures.json) preserves provenance. It does not claim measured learner outcomes.
